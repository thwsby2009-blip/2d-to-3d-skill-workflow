# 驗收協定：三個獨立檢查項與渲染實測

## 零件的三個獨立檢查項

**①本身尺寸（bbox/span）、②渲染中的可見尺寸（實際露出量）、③外輪廓形狀（直邊 vs 內凹）是三個獨立項目**；只驗其中一項，會「修好一處、又退回另一處」。每次修改後三項一起複驗。

推論：

- **頂點跨度 ≠ 可見尺寸**：凸起物要量「露出範圍」（在主殼面之外的部分），不是只看 bbox。
- **曲面在邊中點比角落更前凸**（實測：中心 > 邊中點 > 角落）→ 平面輪廓若「貼合」曲面，必被前凸處切成星形。正解：輪廓保持**平面**，整組沿正前方移出到殼面之前，再用**裙邊（深入殼內約 0.03·特徵尺度）**接回外殼。

## 歧義部位的處理順序

模型有多個相似水平特徵時，「止於某特徵」是歧義的：

1. 用 mesh 實測每個候選位置（凹槽＝半徑局部極小；圈件＝物件 bbox）。
2. 在既有渲染圖上畫 A/B 彩色線＋標籤＋預定終點，給使用者確認。
3. 用絕對座標講明終點；幾何重建使其精確止於該值。
4. **以渲染實測驗收**：把候選點投影成像素列，比對「有／無特徵」兩張渲染的差異最低列。
