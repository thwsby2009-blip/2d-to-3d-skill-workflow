## 重建方式

```bash
blender -b -P scripts/sheep_v11.py        # 建模＋算圖（約 5 分鐘，Cycles CPU）
```

腳本內含量測表（`FRONT` 正面半寬、`SIDE` 側面前/後緣）、`cross_section(u)`（逐高度斷面）、
`surf_front(x,z)`（頭部前表面，臉部色塊貼合用）——所有幾何都是這些量測值的函式。

## 已知偏差（刻意保留）

1. **側面原圖是走路姿勢** → 本模型做成站姿（對 2D 圖唯一合理的 3D 解讀）；側面誤差主要來自這裡
2. **原圖左右耳不對稱**（左耳外張到 −0.447、右耳只到 +0.253）→ 模型取對稱
3. **原圖的深色描邊**（約 117,73,50）→ 3D 用 Freestyle 線稿重現（`views/06_outline.png`），不是幾何
4. **原圖身體有漸層**（下緣偏橘）→ 模型單一奶油色＋打光
5. 腿是等徑圓柱（原圖腿底部略外張、有描邊）
